Лабораторная работа 2



Назначение: реализован процесс ETL для переноса данных из текстовых файлов в базу SQLite.



Требования к окружению:

\- Python 3

\- SQLite3



Исходные файлы в каталоге Task02: movies.csv, ratings.csv, tags.csv, users.txt, genres.txt, occupation.txt.



Файлы решения: make\_db\_init.py, db\_init.bat, db\_init.sql, movies\_rating.db.



Запуск: из каталога Task02 выполнить db\_init.bat. Создаётся база movies\_rating.db с таблицами movies, ratings, tags, users. Время выполнения — менее 2 секунд.
